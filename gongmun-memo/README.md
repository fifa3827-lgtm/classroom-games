# 공문 메모판

업무관리시스템 공문(ODT·HWPX·HWP·PDF)과 붙임(HWP·XLS·ZIP)을 넣거나 본문을 붙여넣으면
날짜를 찾아 메모·달력으로 보여 주는 한 장짜리 도구. 수업 게임이 아니며 대문에는 연결하지 않았다.

## 파일
- `src.html` — 고치는 원본
- `vendor/` — 파일 안에 넣는 읽기 도구(jszip 3.10.1, pako 2.1.0, xlsx 0.18.5)
- `build.py` — `python3 gongmun-memo/build.py` 를 돌리면 `index.html`(배포용, 약 1MB)이 만들어진다
- `index.html` — 만들어진 결과. 직접 고치지 않는다

## 지금 상태 (2026-11-10)
- 넣은 기능: 붙여넣기(Ctrl+V·단추), 오프라인 읽기(PDF만 인터넷 필요), 달력 파일(.ics) 내보내기,
  할 일마다 체크, 달력 칸에 할 일 이름, 지우기 되돌리기, 자동 백업 폴더, 꼬리표·걸러 보기,
  주간 할 일 인쇄, ZIP 통째로 읽기
- 연습용 공문으로 만든 자동 시험(Playwright)은 모두 통과
- **아직 안 한 것**
  - 검수원(`.claude/agents/reviewer.md`) 검수 — 사용자가 철저한 검수를 원함(ChatGPT 검수를 원했으나 이 환경에서는 연결 불가)
  - 실제 공문 파일로 날짜 찾기 확인
