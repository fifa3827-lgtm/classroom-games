# 달빛 오락실 게임 소개 화면 만들기

`intro/<게임폴더>/index.html` 은 손으로 쓰지 않고 이 도구로 만든다.

- `games.py` — 게임마다 들어가는 글 (소개, STEP, 기기 안내, 아이폰·안드로이드). **내용을 고칠 때는 이 파일만 고친다.**
- `intro.css` — 모든 소개 화면이 함께 쓰는 모양 (달빛 오락실 색)
- `build.py` — `games.py` + `intro.css` 로 `out/intro/` 에 페이지를 만든다
- `prep_img.py` — 게임 화면 캡처(shots/)를 `shot0.webp…`, 미리보기 그림 `og.jpg`(1200×630)로 바꾼다

## 지키는 것

- 블로그를 언급하지 않는다. 교실·수업·학생이라는 말도 쓰지 않는다.
- 정답·범인·결말은 쓰지 않는다.
- 기기 안내는 게임 코드를 직접 확인해서 쓴다 (가로/세로, 전체 화면, 홈 화면 추가, 소리, 저장, 백업 코드).
- 「게임 시작」은 달빛 오락실 주소 `/<게임폴더>/` 로 간다. 그래서 깃허브 페이지에서는 버튼이 이어지지 않고, 서버(game.edoori.co.kr)에 올라가야 동작한다.
