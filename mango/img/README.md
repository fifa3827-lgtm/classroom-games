# mango/img — 그림 넣는 곳

제미나이로 뽑은 그림을 **정해진 파일명 그대로** 이 폴더에 넣으면 게임이 바로 씁니다.
프롬프트와 파일명 목록은 [`art/prompts.html`](../art/prompts.html) 을 열어 보세요.

- 파일이 없으면 지금 쓰는 SVG 그림이 그대로 쓰입니다. 깨지지 않습니다.
- 그래서 **한 장씩 넣어도 됩니다.** 콩이만 그림이고 도토는 SVG여도 정상 작동합니다.
- 이름이 한 글자라도 다르면 조용히 SVG가 쓰입니다. 안 바뀌면 파일명을 먼저 확인하세요.
- 배경을 새로 넣었으면 [`art/spots.html`](../art/spots.html) 로 조사 지점 좌표를 다시 찍으세요.

표정 이름: `def` 기본 · `sp` 놀람 · `fl` 네 번째 칸(눈굴림·당황) · `ang` 분노.
표정 파일이 없으면 `-def` 로, 그것도 없으면 SVG로 돌아갑니다.

> 모리의 눈을 똑바로 뜬 표정은 **사건 18 전용**입니다. 지금 만들지 마세요 —
> 미리 나오면 시즌1 최대 연출 장치가 죽습니다(바이블 9.3).
