# 쵸코와 한글

한글이 처음인 저학년 학생을 위한 소리 중심 한글 놀이. 고양이 쵸코가 안내한다.
태블릿·스마트폰 세로 화면에 맞춰져 있고, 기기에 내장된 한국어 음성(TTS)으로 모든 글자와 낱말을 읽어 준다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (화면·소리·저장). 보통 고칠 필요 없음 |
| `data.js` | 설정, 자모·낱말, 활동 목록, 쵸코 대사. **여기만 고치면 내용이 바뀐다** |
| `choco/` | (선택) 학생이 그린 쵸코 그림. `idle.png` `cheer.png` `happy.png` `retry.png` 4장을 넣으면 내장 그림 대신 표시 |
| `worksheets/` | (예정) 인쇄 학습지 PDF |

## 현재 단계 (M1)

1단계 「소리 마을」 9개 활동. 활동 하나는 문제 6개, 약 3분.

| 활동 | 방식 |
|---|---|
| 모음 첫걸음 / 모음 더하기 / 자음 첫걸음 / 자음 더하기 / 센 소리 | 소리를 듣고 글자 4개 중 고르기 |
| 어? 오? 으? 우? / 그? 크? 끄? | 헷갈리는 소리 짝 구별 (발음 코너) |
| 글자와 그림 1·2 | 글자를 보고 그 소리로 시작하는 그림 낱말 고르기 |

별: 6문제를 모두 첫 시도에 맞히면 ★★★, 4~5개면 ★★, 그 아래는 ★. 별은 기기에 저장되며 최고 기록만 남는다.

## 선생님 모드

홈 화면에서 쵸코를 3초 안에 5번 톡톡 → 비밀번호(기본 `1234`, `data.js`의 `teacherPin`).

- 학생 별칭: 시트에 기록되는 이름. 실명 대신 `cat01`처럼 쓴다.
- 구글 Apps Script 웹앱 주소: 아래 「진도 기록」 참고. 비우면 기기 안에만 저장.
- 소리 속도, 열린 단계, 영어 뜻 표시 켜기/끄기
- 최근 기록 20건, 대기 중 기록 보내기, 진도 초기화

## 진도 기록을 구글 시트로 보내기 (M2에서 안내 예정)

1. 구글 시트를 하나 만들고 확장 프로그램 → Apps Script를 연다.
2. 아래 코드를 붙이고 「배포 → 새 배포 → 웹 앱, 액세스: 모든 사용자」로 배포한다.
3. 나온 웹앱 주소(`.../exec`)를 선생님 모드의 주소 칸에 넣는다.

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0)
    sheet.appendRow(["학생", "일시", "단계", "활동", "별", "첫시도정답", "문제수", "틀린글자"]);
  var body = JSON.parse(e.postData.contents);
  (body.records || []).forEach(function (r) {
    sheet.appendRow([r.code, r.at, r.stage, r.lesson, r.stars, r.firstTry, r.total, r.misses]);
  });
  return ContentService.createTextOutput("ok");
}
```

전송에 실패한 기록은 기기에 남아 있다가 다음 접속 때 다시 보낸다.

## 내용 바꾸기 (`data.js`)

- 낱말 바꾸기: `jamo` 안에서 `words: [["고양이", "🐱", "cat"], ...]` 형식. 첫 글자 소리가 해당 자모여야 한다.
- 활동 추가: `lessons`에 한 줄 추가. `kind`는 `listen`(듣고 고르기) / `picture`(글자→그림) / `pair`(소리 짝).
- 쵸코 대사: `choco` 항목.

## 소리가 안 날 때

- 기기 음소거·볼륨 확인. 첫 화면의 「시작」을 눌러야 소리가 켜진다(브라우저 규칙).
- iPad: 설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 한국어 음성이 있는지 확인.
- 안드로이드: 설정 → 일반 → 텍스트 음성 변환(TTS) → 한국어 음성 데이터 설치.
