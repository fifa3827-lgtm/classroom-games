## 교사용 정답표

### 책 추천 상담원
읽을 사람(초등 1·2 / 3·4 / 5·6학년, 중·고등학생, 성인)을 고른 뒤 설문 또는 사연으로 세 권을 추천받는다. 고정 목록이 아니라 그때그때 서점·도서관 데이터를 받아 고른다.

- 데이터: **카카오 책 검색 API**(믿을 만한 어린이·청소년·문학 출판사 40여 곳의 최신 도서를 매번 12곳씩 무작위로 조회 + 관심 주제·사연 낱말 검색) ＋ **도서관 정보나루 API**(연령별 인기대출, 선택). 알라딘 OpenAPI는 2026-09 신규 발급 중단으로 쓰지 않는다.
- 학년 가르기: 소개글의 단서(저학년·중학년·고학년·청소년 등)와 부가기호. 문제집·세트·월간지·자가출판·예약도서는 제외.
- 설문: 지금 필요한 책(마음) · 관심 주제(여러 개) · 독서 습관 · 이야기/지식 · 우리나라/다른 나라 작가. 맞는 점은 카드에 초록 태그로 표시. 「다시 뽑기」는 상위 12권 중 가중 무작위라 매번 다르다. 「올해 나온 책만」 스위치 있음.
- 직접 이야기하기: 사연에서 낱말(고양이, 그림, 친구…)을 뽑아 검색하고 마음·주제를 설문에 자동 반영.
- **API 키는 저장소에 넣지 않는다.** 페이지는 주소 뒤 `#k=카카오키&d=정보나루키` 를 읽어 브라우저(localStorage)에 저장하므로, 공유는 키가 담긴 링크로 한다. 키가 없으면 페이지 안 입력칸이 나온다. 키 유출 시 카카오 콘솔에서 새 키를 만들고 링크만 바꾸면 된다.
- 조회는 같은 요청을 60분 캐시(sessionStorage). 한 번 추천에 6~20회 호출, 카카오 하루 한도 3만 회.
- 배경음악: 오른쪽 위 버튼으로 켜고 끔(기본 꺼짐, 한 번 켠 기기는 다음 방문 첫 터치에 이어서). `bookclinic/bgm.mp3`는 Suno로 만든 「서가의 오후」(2026-09-10); 파일이 없으면 페이지가 Web Audio로 직접 연주하는 앰비언트로 대체된다. 곡을 바꾸려면 같은 이름으로 덮어쓰면 된다.

### 사라진 타임캡슐
학교 100번째 생일 전날, 1996년 6학년 선배들이 남긴 편지를 따라 지도 조각 5개를 모으는 이야기.

| 단계 | 장소 | 문제 유형 | 정답 | 얻는 숫자 |
|---|---|---|---|---|
| 1 | 도서관 | 스티커 순서대로 책 제목 첫 글자 잇기 | 은행나무 | 1 |
| 2 | 음악실 | 피아노 멜로디 듣고 따라 치기 | 미 솔 라 솔 도 레 | 9 |
| 3 | 과학실 | 무게 비교 추리 (가장 가벼운 상자) | 초록 상자 | 9 |
| 4 | 급식실 | 그림 암호 해독 (🍌 = 🍎+🍞 = 6) | 7624 | 6 |

- 음악은 「탐정 시작」을 누르면 자동으로 켜지고, 오른쪽 위 🎵 버튼으로 끌 수 있음.

### 퍼즐 25
다섯 가지 퍼즐이 번갈아 나오며 5바퀴(몸풀기·익히기·본격·도전·끝판) 동안 어려워진다. 앞 단계를 깨야 다음이 열린다.
(2026-09-09: 「불 끄기」가 어렵다는 의견이 많아 「주차장 탈출」로 교체했다.)

| 순서 | 퍼즐 | 규칙 한 줄 | 단계별 크기 | 막혔을 때 |
|---|---|---|---|---|
| 1 | 주차장 탈출 | 빨간 차를 오른쪽 출구로. 차는 놓인 방향으로만 밀림 | 6×6 고정, 차 6대 → 11대 | 빨간 차 앞을 막은 차부터, 그 차를 막은 차를 먼저 치우기 |
| 2 | 파이프 잇기 | 칸을 눌러 90도 회전, 끊긴 곳 없이 하나로 | 3×3 → 7×7 | 끝이 막힌 관(점 하나)부터 맞추기 |
| 3 | 미로 | 왼쪽 위에서 오른쪽 아래 주황 칸까지 | 7×7 → 15×15 | 오른손 벽 따라가기 |
| 4 | 한 붓 그리기 | 점을 눌러 모든 선을 한 번씩만 | 5선 → 12선 | 홀수 선이 모인 점에서 출발 |
| 5 | 물 붓기 | 같은 색 위나 빈 병에만 부어 병마다 한 색 | 3색 → 6색(마지막은 5층) | 빈 병 두 개를 비워 두기 |

- 모든 단계는 풀 수 있음이 프로그램으로 확인됨. 같은 단계는 누가 열어도 같은 판이라 횟수 비교 가능.
- 주차장 탈출 최소 수순(화면 왼쪽 아래에도 표시): 1단계 6회 · 6단계 8회 · 11단계 11회 · 16단계 17회 · 21단계 22회. 차 하나를 한 번 미는 것이 1회.
- 되돌리기(한 수 취소)·다시 시작 버튼 있음. 소리는 오른쪽 위 🔊로 끔.
- 진행 상황은 기기 브라우저에 저장. 초기화는 목록 맨 아래 「기록 지우기」.

### 천공비행단 1945
스트라이커즈 1945 방식의 세로 스크롤 비행 슈팅. 시작 화면에서 기체를 고르고(좌우 탭 · ← → · 숫자 1~5), 가운데를 탭하면 출격. 사격은 자동.

| 기체 | 주무장 | 폭탄 | 특징 |
|---|---|---|---|
| 참매 F-1 | 쌍발 직사포, 5단에서 확산+유도탄 | 대형 폭탄 — 전 화면 폭발 | 균형형, 처음 하는 사람에게 권장 |
| 창 P-2 | 고속 관통 철갑탄 (4단부터 관통) | 융단 폭격 — 위에서 아래로 폭탄이 쏟아짐 | 가장 빠름, 좁고 강함 |
| 부채 S-3 | 광각 산탄 3→11발 | 폭풍 방벽 — 6초 무적, 닿는 적 파괴 | 화면 넓게 커버, 화력 약함 |
| 솔개 K-4 | 유도 미사일 자동 조준 | 유도탄 폭우 — 16발 일제 발사 | 조준이 서툴러도 됨, 폭탄 4개 |
| 곰 B-5 | 중포 + 3단부터 광역 레이저 | 섬멸 광선 — 3초간 전방 관통 | 느림, 기체 1대 더 있음, 폭탄 2개 |

| 스테이지 | 이름 | 보스 | 특징 |
|---|---|---|---|
| 1 | 동해 상공 | 수상요새 「해룡」 | 기본 편대, 지상 포대 |
| 2 | 폭풍 전선 | 중폭격기 「흑뢰」 | 야간, 폭격기·에이스 등장 |
| 3 | 요새 상공 | 공중전함 「천공」 | 포대 4기, 밀도 상승 |
| 4 | 빙하 해협 | 쇄빙순양함 「백호」 | 부유 지뢰(파괴 시 8방향 파편), 급강하 헌터 |
| 5 | 화산 본토 | 화산포대 「염제」 | 전 적 종류 총력전 |

- 5스테이지 보스를 잡으면 LOOP 2로 1스테이지부터 반복 (적 체력·탄속·점수 배율 상승). 후반 스테이지 보스는 연사 간격이 짧아짐.
- 보스는 체력 62% / 30% 지점에서 패턴이 바뀐다(조준탄 → 원형 탄막 → 유도탄 추가).
- 아이템: P 주무장 강화(최대 5단) · B 폭탄 · S 실드 5초 · ★ 2000점. 편대의 마지막 기체가 떨어뜨린다. 피격 시 주무장 1단 하락.
- 모바일: 화면 아무 곳이나 누른 채 끌면 기체가 손가락 이동량의 1.25배로 따라옴(손가락이 기체를 가리지 않음). 이동 중 다른 손가락 탭 = 폭탄. FULL 버튼으로 전체화면(iPhone Safari 제외). 가로로 돌리면 세로 안내가 뜬다.
- PC: 방향키/WASD 이동, SPACE 폭탄, P 일시정지. 최고 점수와 마지막 선택 기체는 브라우저에 저장.
- 소리는 파일 없이 Web Audio로 합성(효과음 + 스테이지별 템포가 오르는 BGM). SOUND 버튼으로 끔. 원본은 Claude 아티팩트(striker.html)에서 수정 후 sky1945/index.html로 내보낸다.

## 새 게임 추가하는 법

1. 영어 소문자 폴더를 하나 만든다. (예: word-hunt/)
2. 그 안에 index.html 을 넣는다. 파일 하나에 HTML·CSS·JS를 모두 담아야 태블릿에서 그대로 열린다.
3. 루트의 index.html(대문)에 카드 하나를 추가한다.
4. 이 README의 게임 목록 표와 정답표에 한 줄을 적는다.

## 파일 규칙

- 폴더·파일 이름은 영어 소문자와 하이픈만 사용. 한글 이름은 주소에서 깨질 수 있음.
- 화면에 보이는 한글 제목은 파일 안의 <title>과 본문에 적는다.
- 외부 이미지·음원 파일 대신 이모지, CSS, Web Audio로 만들면 파일 하나로 끝나서 관리가 쉽다.
### 물풍선 대작전
크레이지 아케이드 방식. 물풍선을 놓으면 2.4초 뒤 십자로 물줄기가 터지고, 상자를 부수면 아이템(🎈 풍선 개수 · 💧 물줄기 길이 · 👟 속도 · 💗 하트)이 나온다. 물줄기에 맞은 캐릭터는 물방울에 갇힌다.

| 모드 | 진행 | 규칙 |
|---|---|---|
| 혼자 하기 | 5스테이지, 하트 3개 | 스테이지의 적(느림보·추격이·풍선마·날쌘돌이)을 모두 물방울에 가두면 클리어. 남은 시간×5점 보너스. 아이템은 다음 스테이지로 유지 |
| 온라인 대결 | 3판 2선승, 최대 4명 | 「방 만들기」로 4글자 코드를 받고, 상대는 같은 페이지에서 코드 입력 → 참가. 마지막까지 남은 사람이 라운드 승리. 갇힌 상대를 건드리면 즉시 터뜨릴 수 있음. 라운드마다 아이템 초기화, 라운드 2분. 방해꾼 AI 0~2명 선택 |

- 조작: 방향키/WASD + Space, 또는 화면 방향패드 + 물풍선 버튼(🕹 버튼으로 켜고 끔). 소리는 🔔(효과음) 🎵(BGM)로 끔.
- 온라인 연결은 PeerJS(WebRTC) 기기 간 직접 연결이라 로그인이 필요 없다. 방을 만든 사람(호스트)이 게임을 진행하므로 호스트가 나가면 모두 로비로 돌아간다. 학교 와이파이 등 일부 망에서는 연결이 안 될 수 있으니 그럴 땐 휴대폰 데이터로 시도.
- 이 저장소 버전 외에, 같은 조직 로그인 사용자끼리 붙는 claude.ai 아티팩트 버전도 따로 있음(2026-09-11).
