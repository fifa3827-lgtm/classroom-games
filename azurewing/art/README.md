# 그림 교체 (제미나이 등)

이 폴더에 PNG를 넣고 `manifest.json`에 이름을 적으면, 코드로 그린 그림 대신 그 그림이 쓰입니다.
없는 그림은 원래 코드 그림이 그대로 나옵니다.

```json
["hawk", "fighter", "seadragon"]
```

## 그림 규칙
- **위에서 내려다본 모습, 기수(앞)가 화면 위쪽**을 향하게 (적기·보스도 위를 향하게 그리면 게임이 뒤집어 씀)
- **투명 배경 PNG**, 그림자 없이 (그림자는 게임이 자동으로 그림)
- 빛은 **왼쪽 위**에서
- 기체가 그림을 꽉 채우도록 여백을 거의 두지 않기
- 그림을 넣으면 프로펠러 회전 효과는 빠집니다 (그림에 프로펠러를 흐릿하게 그려 넣으면 자연스러워요)
